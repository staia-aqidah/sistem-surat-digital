Sistem untuk cetak surat administrasi di Kampus Al-Aqidah secara otomatis.

- Di buat dengan php
- Digunakan khusus pada plugin Wordpress
- Add to archive .zip, setelah itu di Wordpress admin add plugins --> Upload --> lalu upload hasil archive.zip

- Wordpress harus terinstall (Elementor / alternatif)
- Buat page, dan tambahkan widget 'shortcode'
- Pada widget 'shortcode' isi value --> [form_surat]
- Otomatis tampilan menu surat digital akan muncul
